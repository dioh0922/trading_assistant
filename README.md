# Trading Assistant 実行コマンドリファレンス

本プロジェクト (`trading_assistant`) の実行コマンドの一覧と使用方法をまとめたリファレンスです。

---

## 1. 基本的な実行

プロジェクトのパイプライン全体を実行します。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py` | `resource/sample.xlsx` を用いて、デフォルト設定（ATRモード）でパイプラインを実行します。 |
| `python main.py --code 6981` | 指定した銘柄コード（例: `6981`）に対応するデータファイル `resource/6981.xlsx` を用いて実行します。 |

---

## 2. バリアモード（利確・損切り）の切り替え

ステップ3におけるトリプルバリア法のバリア設定を変更して実行します。

### A. ATRモード (デフォルト)
ATR（Avarage True Range）に基づいた可変のバリアを設定します。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --barrier-mode atr` | ATRモードを明示的に指定して実行します。 |
| `python main.py --barrier-mode atr --tp-atr-mult 2.5 --sl-atr-mult 1.0 --holding-period 15` | 利確を ATR × 2.5、損切りを ATR × 1.0、最大保有営業日数を 15日 にカスタマイズして実行します。 |

### B. 固定パーセントモード
固定値（%）のバリアを設定します。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --barrier-mode fixed_pct` | 固定%モードをデフォルト値（利確 +10% / 損切り -5%）で実行します。 |
| `python main.py --barrier-mode fixed_pct --tp-pct 0.10 --sl-pct 0.05` | 利確を +10% (`0.10`)、損切りを -5% (`0.05`) に設定して実行します。 |
| `python main.py --tp-pct 0.10 --sl-pct 0.05` | `--barrier-mode` の指定を省略した場合でも、パーセントを指定すると自動的に固定%モードで動作します。 |

---

## 3. ステップ6 (意思決定フィルタ) のカスタマイズ

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --no-step6` | ステップ6の意思決定フィルタを無効化し、ステップ5までの定量判断で停止します。 |
| `python main.py --drawdown-prob-limit 0.60` | ドローダウン予測モデルの確率閾値を `0.60` に設定してMLフィルタを併用します（デフォルト値 `1.0` はMLフィルタ無効＝ATRルールのみ適用）。 |

---

## 4. クイックレポート（今日のシグナル出力）

パイプラインの再実行（学習処理など）を行わず、既存の算出結果から当日の判断結果のみを素早く出力します。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --code 7701 --today` | `7701` 銘柄の保存済みデータ（`step6_dataset.csv` など）から、今日のエントリー判断レポートのみを生成して出力します。 |

---

## 5. スキャン（スクリーニング）モード

`resource/` ディレクトリ配下にある複数のExcelデータに対して一括で処理を行います。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --scan` | 全ての4桁コードのExcelファイルをスキャンし、一括スクリーニングを実行します。 |
| `python main.py --scan --force` | キャッシュ（中間ファイル）を無視し、全銘柄のパイプライン処理を強制的に再実行してスキャンします。 |

---

## 6. ステップ9: 目標額到達推定

指定した目標価格に到達する確率（経験的確率・モンテカルロシミュレーション）と期待日数を推定します。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --code 6981 --target-price 5000` | 目標価格を `5000円` に指定して到達確率を推定します。（現在の終値より高い値を指定する必要があります） |
| `python main.py --code 6981 --target-pct 0.15` | 現在価格から `+15%` (`0.15`) 上昇した価格を目標価格として推定します。 |

---

## 7. ステップ10・11: LLM統合（定性・定量ハイブリッド）

定量データと定性分析を統合し、LLMによる最終エントリー判断を行います。

| コマンド | 説明 |
| :--- | :--- |
| `python main.py --build-prompt` | **[Step10]** 最新の定量データからLLM用の構造化プロンプトテキスト (`llm_prompt.txt`) のみを生成・保存します。 |
| `python main.py --llm` | **[Step11]** LLM推論を実行し、定性・定量ハイブリッドレポートを出力・保存します（デフォルトはモックプロバイダを使用）。 |
| `python main.py --llm --llm-provider gemini` | プロバイダに Gemini を指定してLLM推論を実行します（事前に `GEMINI_API_KEY` の設定が必要です）。 |
| `python main.py --llm --llm-provider openai` | プロバイダに OpenAI を指定してLLM推論を実行します（事前に `OPENAI_API_KEY` の設定が必要です）。 |
| `python main.py --code 6981 --target-pct 0.10 --llm` | 目標到達推定（Step9）の情報もプロンプトに内包させた上で、LLMによるハイブリッド判断を実行します。 |
